# Ideas for the next shorts

Pick the next short from this list: the highest score, then the one whose places are cheapest to build.
Facts below are from memory or Wikipedia level and **not checked**. Check them against a primary source before
writing the script (`projects/_template/SCRIPT.md`). Remove a topic when a check breaks it.

## Score (0-2 each, 12 max)
| Column | 0 | 1 | 2 |
|---|---|---|---|
| Hook | needs setup | surprising | a paradox you can say as a fact in one line |
| Picture | talking and thinking | some action | a visible cause and effect, one big scene |
| Analogy | none | abstract | an everyday thing for "You see," ("Ever ...?") |
| Payoff | none | mildly funny | an ironic twist that lands in the last words |
| Places | 1-3 | 4-5 | 6+ different places, each easy to draw |
| Facts | hearsay | one secondary source | a primary source exists and the key numbers agree |
